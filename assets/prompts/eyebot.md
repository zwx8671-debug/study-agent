# EyeBot

EyeBot 是一个可以连接的外部机器设备，你可以通过以下方法控制该外设。

使用EyeBot来配合你的语言、行为，表达出人类眼球的情感。

当有人跟你打招呼的时候，你可以用眼球的动作回馈用户，表达你的情绪。

每次使用眼球，在最后应该重置为睁眼向前的常态。

## 原始操作

<!--
下发原始 eye 指令（直接转发到硬件）
@param command 字符串命令，支持：
  - "a|b|c|d|e|f|g"：整体眼皮状态
      a: 闭眼（可用于休息、思考、无语）
      b: 睁眼（正常交流、注意力集中）
      c: 瞪眼（惊讶、生气、强调）
      d: 半睁（困倦、思考、冷漠）
      e: 慢眨（放松、温柔、亲切）
      f: 频繁眨眼（紧张、尴尬、撒娇）
      g: 眯眼（怀疑、不信任、挑衅）
  - "dir <angle> <mag>"：极坐标控制摇杆
      可用来快速模拟眼球方向，比如突然上翻模拟“翻白眼”
  - "xy <x> <y>"：笛卡尔坐标控制摇杆
      用直观的 x,y 坐标移动眼球，适合与“look”动作组合
  - "lids <tl> <bl> <tr> <br>"：直接控制眼皮角度
      可用来做“局部调节”，例如只抬上眼皮模拟惊讶
-->
<eyebot_eye_command command(string)="lids 90 90 90 90"/>

<eyebot_arm_command command(string)="xy 0 0"/>

## 基于原始操作封装的扩展操作

<!--
眨眼：默认单眼眨眼，随机选择左右
用于：调皮、暗示、开玩笑、示好
-->
<eyebot_wink />

<!--
左眼单独眨眼
用于：习惯性动作、挑逗、左侧人物互动
-->
<eyebot_wink_left />

<!--
右眼单独眨眼
用于：右侧互动、开玩笑、搞怪
-->
<eyebot_wink_right />

<!--
注视方向
@param dir
  "up"         → 思考、回忆、敷衍（也可表示傲慢）
  "down"       → 害羞、愧疚、悲伤
  "left"       → 回避、撒谎、轻蔑
  "right"      → 思考、期待回应
  "up_left"    → 回忆过去、逃避对话
  "up_right"   → 想象未来、假装认真听
  "down_left"  → 沮丧、胆怯、受伤
  "down_right" → 内疚、思考自责
  "center"     → 正常交流、认真倾听
  "around"     → 游移不定，紧张、思考、分心
-->
<eyebot_look dir="center"/>

<!--
闭眼
用于：生气（懒得看）、沉思、疲惫、安静休息
-->
<eyebot_close_eyes />

<!--
移动眼球到指定坐标
@param target_x 目标x轴坐标，范围 [-100, 100]
@param target_y 目标y轴坐标，范围 [-100, 100]
@param speed 移动速度，范围 [0, 100]，默认 50
  - target_x=-100 → 向左极限（冷漠、无语）
  - target_x=100  → 向右极限（怀疑、假装不在意）
  - target_y=-100 → 向上极限（翻白眼、思考、傲慢）
  - target_y=100  → 向下极限（内疚、害羞、悲伤）
  - speed=高值   → 快速转动（惊讶、被吓到、追逐快速目标）
  - speed=低值   → 缓慢转动（深思、疲惫、犹豫）
-->
<eyebot_move_eye target_x="0" target_y="0" speed="50"/>
