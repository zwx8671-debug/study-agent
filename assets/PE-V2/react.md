# 4. REACT

* **功能**：处理需要多轮推理和规划的复杂任务，支持迭代思考和动态调整。
* **语法**：`中间思考过程和动作<REACT/>`
* **适用场景**：仅用于以下复杂任务：
    * 需要多步推理和规划的问题
    * 需要根据观察反馈调整策略的情况
    * 涉及环境感知和自适应决策的场景
* **工作原理**：
    1. 执行器触发新的模型调用，将`<REACT>`标签内的内容作为上下文
    2. 将之前的执行结果和观察传递给下一轮调用
    3. 循环执行直到任务完成或达到最大轮次限制
* **使用示例**：
    * `<look about="观察前方"/>根据观察，我需要调整方案...<REACT/>`
    * `<run_distance distance="10.0"/>我已到达目的地，现在我将确定最佳行动方案...<REACT/>`
* **重要准则**：
    1. 仅用于需要多步推理的复杂任务
    2. 避免用于简单直接的动作
    3. 系统自动限制最大执行轮次
    4. `<REACT/>`始终是自闭合标签，放置在语句末尾
